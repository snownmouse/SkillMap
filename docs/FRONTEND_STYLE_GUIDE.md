# 🎨 个人成长与奥德赛实习：前端美学风格指南 (Meadow Mist)

**风格命名**：“晨雾原野” (Meadow Mist) —— 融合春日清晨的薄雾、原野的柔和色彩、以及探索路径的轻盈感。
**核心诉求**：温暖、生机、叙事感、现代、不幼稚、不依赖绿色、颜色好看。

## 一、色彩系统（温暖、通透、高级）

| 用途 | 色值 | 描述 |
|------|------|------|
| 背景 | `#FDF8F0` → `#F4ECE5` 垂直渐变 | 像亚麻纸或晨光中的淡米色，极暖，不刺眼 |
| 毛玻璃卡片 | `rgba(255, 250, 240, 0.7)` + 模糊 | 暖白透明，带极细的暖色阴影 |
| 主色调（生机/成长） | `#E89F6E`（陶土橙） & `#F3C26B`（麦秆黄） | 像春天田野里的暖光，不绿但生机勃勃 |
| 辅助色 | `#9CB4B3`（鼠尾草灰绿） & `#D6B0A5`（干枯玫瑰） | 极低饱和度的冷色作平衡，避免过暖 |
| 高亮/互动 | `#FF8A5C`（珊瑚橙） | 用于按钮、解锁、链接 |
| 文字 | 深褐灰 `#2E2A28` / 中灰 `#6B5E55` | 保持可读性，温暖不刺眼 |

> **设计注记**：这套配色类似 Studio Ghibli 日常场景或 Modern Organic 设计——不饱和到发灰，也不艳俗，有手作的温度但干净。

## 二、视觉形态（轻盈、有机、有叙事）

- **技能树**：不再是传统树形。采用**漂浮的卡片岛屿**，每个技能是一张圆角卡片（像植物标本标签），卡片之间用**极细的暖色棉线或虚线**连接。已解锁的卡片有轻微的“折角”或“压花”效果。
- **聊天界面**：对话框采用**不对称的气泡**，用户消息右侧，像手写信笺；AI消息左侧，像便签纸。每条消息下方可以有一个小小的“成长印记”——一朵简笔小花、一颗种子、一个脚印，随解锁进度变化。
- **背景装饰**：极浅的水彩晕染色块（淡橙、淡黄、淡灰蓝），位置随机但固定，像画纸上的底色。加上偶尔飘落的蒲公英绒毛（极慢动画）。

## 三、动态美学（温柔、鼓励感）

- **页面加载**：背景色从浅米渐显，然后卡片从底部轻盈上浮，像晨雾散去后原野显现。
- **解锁技能**：对应的卡片边缘出现**水彩扩散的晕染动画**（颜色为陶土橙），然后卡片上浮现一行手写日期和“已探索”。伴有极轻微的“啵”声（可选）。
- **聊天发送**：消息气泡从输入框“生长”出来，带着弹性的拉伸回弹。AI回复前，显示三个跳动的小点，下面有一行小字“正在为你描绘路径...”
- **滚动效果**：卡片有视差——前景移动稍快，背景晕染色块几乎不动，增强空间感。

## 四、字体与图标

- **字体**：
  - 正文：**Inter** 或 **Plus Jakarta Sans**（干净现代）
  - 日期和用户名：**Caveat** 手写体
  - 技能名称：**Instrument Serif** 或 **Georgia**（带一点书香）
- **图标**：线性描边 + 手绘质感（类似 **Heroicons** 但更圆润），解锁后图标填充淡淡的暖色。

## 五、氛围音效（可选）

- **背景**：田野白噪音（微风、远处鸟鸣）或轻柔的吉他拨弦。
- **解锁**：木琴或铃铛的短音。
- **发送消息**：羽毛笔尖划过纸面的声音。

## 💡 核心理念与一句话风格描述

> “像走在春日清晨的原野上，薄雾未散，露珠闪烁，你的每一步成长都被温柔地记录在这本会呼吸的笔记里。”

### 三个核心理念词（可直接给设计者）

1. **晨雾原野**（温暖米白基底 + 陶土橙麦秆黄 + 极低饱和冷色点缀）
2. **手绘标本**（卡片像植物标签，连接线像棉线，动态像水彩晕染）
3. **轻盈叙事**（不对称对话框、成长印记、弹性动效）

---
*注：本方案完全抛弃了蓝色科技风和纯绿色，用温暖米白 + 陶土橙 + 鼠尾草灰绿（极低饱和）打造出春天、成长、奥德赛的感觉。*
