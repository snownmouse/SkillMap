# 内测版与主项目文件差异说明

## 概述

本文档对比分析「内测版」与「主项目」的文件结构差异，帮助了解两个版本之间的功能范围和代码组织差异。

---

## 一、目录结构对比

### 1.1 整体目录对比

| 类别 | 主项目 | 内测版 | 差异说明 |
|------|--------|--------|----------|
| **配置文件** | 完整 | 精简 | 主项目包含 Docker、PM2 配置 |
| **文档** | 丰富（16个文件） | 基础（3个文件） | 主项目包含完整技术文档 |
| **脚本** | 数据库迁移脚本 | 无 | 主项目支持数据库迁移 |
| **测试** | 单元测试 | 无 | 主项目有完整测试覆盖 |
| **日志** | 日志目录 | 无 | 主项目有日志管理 |
| **后端服务** | 完整后端 | 简化后端 | 主项目功能更全面 |

### 1.2 根目录文件对比

**主项目独有文件：**
- `.github/workflows/ci.yml` - CI/CD 工作流
- `Dockerfile` - Docker 镜像构建
- `docker-compose.yml` - Docker Compose 配置
- `ecosystem.config.cjs` - PM2 进程管理
- `replace-colors.js` - 颜色替换脚本
- `replace-white.js` - 白色替换脚本
- `replace-white2.js` - 白色替换脚本（版本2）
- `worker.ts` - 后台工作进程
- `metadata.json` - 元数据配置

**内测版独有文件：**
- `install.bat` - Windows 安装脚本
- `uninstall.bat` - Windows 卸载脚本
- `skillmap.exe` - Windows 可执行程序

## 五、总结

### 5.1 版本定位

| 版本 | 定位 | 适用场景 |
|------|------|----------|
| **主项目** | 完整功能版本 | 生产环境部署、全功能开发 |
| **内测版** | 简化演示版本 | 快速预览、本地体验 |

### 5.2 核心差异总结

1. **功能完整性**：主项目包含职业测评、规划、目标管理等完整功能链
2. **架构复杂度**：主项目采用微服务架构，支持分布式部署
3. **运维能力**：主项目支持 Docker、PM2、CI/CD 等运维工具
4. **测试覆盖**：主项目有单元测试和压力测试
5. **监控能力**：主项目有完整的监控、追踪、限流体系

### 5.3 迁移建议

如需将内测版功能迁移至主项目，需关注：
- 数据库表结构差异（主项目有更多表和迁移文件）
- API 路由差异（主项目有更多路由端点）
- LLM 配置差异（主项目支持多提供商）
- 服务依赖差异（主项目依赖 Redis 等中间件）
