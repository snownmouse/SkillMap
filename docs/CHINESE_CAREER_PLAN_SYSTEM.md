# 中国特色生涯规划自主知识体系设计稿

## 版本：v2.0

### 背景与目标

本文档基于《中国特色生涯教育自主知识体系建构》论文的理论框架，结合项目原有西方生涯教育理论（霍兰德职业兴趣理论、职业锚理论、SMART目标等），设计一套**中西融合的中国特色生涯规划体系**。

---

## 一、理论框架重构

### 1.1 原有西方理论保留

| 理论 | 核心价值 | 保留原因 |
|------|---------|---------|
| Holland Code（霍兰德） | 职业兴趣匹配 | 国际通用，工具成熟 |
| Career Anchors（职业锚） | 职业价值取向 | 自我认知的重要维度 |
| SMART Goals | 目标设定方法 | 可操作性强 |
| Bloom's Taxonomy | 认知层级递进 | 学习路径设计科学 |
| Deliberate Practice | 刻意练习 | 技能习得核心机制 |

### 1.2 中国特色理论融入

#### 核心理论支柱

**① 马克思主义人的全面发展理论**
- 人的本质是社会关系的总和
- 人的自由而全面的发展
- 教育与生产劳动相结合

**② 中华优秀传统文化精华**
- 修齐治平、兴亡有责的家国情怀
- 富民厚生、义利兼顾的经济伦理
- 厚德载物、明德弘道的精神追求

**③ 中国特色社会主义教育理论**
- 为党育人、为国育才
- 理论联系实际、密切联系群众
- 立德树人

## 二、职业路径设计重构

### 2.1 原有路径保留

| 路径ID | 路径名称 | 描述 |
|--------|---------|------|
| tech | 技术深耕路线 | 追求专业深度和技术专家地位 |
| management | 管理发展路线 | 追求领导权力和团队管理 |
| slash | 复合发展路线 | 技术+管理双轨发展 |

### 2.2 新增中国特色路径

| 路径ID | 路径名称 | 描述 | 对应国情 |
|--------|---------|------|---------|
| grassroot | 基层锻炼路线 | 到基层去、到西部去、到祖国最需要的地方去 | 响应国家号召 |
| national_strategy | 国家战略路线 | 人工智能、芯片、新能源等国家重点领域 | 科技自立自强 |
| rural_revival | 乡村振兴路线 | 服务农村广阔天地 | 教育强国建设 |
| stable_development | 稳定发展路线 | 求稳务实，服务民生需求 | 安全稳定导向 |

### 2.3 路径匹配维度

每条路径评估五个维度：

```
PathEvaluation {
  personalMatch: number;      // 个人兴趣/能力匹配度 (0-100)
  skillTransfer: number;      // 可迁移技能积累度 (0-100)
  socialValue: number;       // 社会价值贡献度 (0-100)
  nationalDemand: number;     // 国家战略需求度 (0-100)
  culturalAlignment: number; // 文化价值契合度 (0-100)
}
```

## 三、目标设定重构

### 3.1 SMART目标 + 中国特色

原有SMART目标体系保持，增加以下维度：

| 维度 | 说明 | 问题示例 |
|------|------|---------|
| **人民性** (Mínshēnxìng) | 服务人民群众的切实需求 | 这个目标如何解决人民群众的实际问题？ |
| **时代性** (Shídài xìng) | 与国家发展同频共振 | 这个目标如何响应时代号召？ |
| **实践性** (Shíjiàn xìng) | 理论联系实际，基层实践 | 如何在实践中检验和实现这个目标？ |

### 3.2 目标分级

```
GoalLevel {
  personal: "个人发展目标"    // 个人技能提升、职业晋升
  social: "社会责任目标"      // 服务社会、帮助他人
  national: "国家贡献目标"     // 响应国家战略、投身重点领域
}
```

## 四、评估体系重构

### 4.1 新增fitScore多维评估

```typescript
interface ChineseCareerFitScore {
  hollandMatch: number;        // 霍兰德兴趣匹配度
  careerAnchorMatch: number;    // 职业锚匹配度
  nationalDemand: number;       // 国家战略需求匹配度
  socialContribution: number;  // 社会贡献预期
  culturalHeritage: number;    // 文化传承价值
  grassrootWillingness: number; // 基层锻炼意愿
  finalScore: number;          // 综合推荐指数
}
```

### 4.2 评估问题重构

| 原问题 | 新增问题 |
|--------|---------|
| "你的兴趣是什么？" | "你愿意到基层去锻炼吗？" |
| "你想赚多少钱？" | "你如何看待个人利益与社会责任的关系？" |
| "你的职业目标是什么？" | "你的职业选择如何与国家发展同频共振？" |

## 七、核心设计原则

1. **中体西用**：以中国特色理论为主体框架，融合西方科学方法
2. **知行合一**：理论指导与实践锻炼并重
3. **家国同构**：个人发展与国家命运紧密相连
4. **义利兼顾**：正当利益追求与社会责任统一
5. **与时俱进**：响应国家发展战略，顺应时代需求
