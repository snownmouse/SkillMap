# SkillMap（技能地图）—— 产品亮点与技术优势

## 一、产品概述

SkillMap 是一款**对话驱动的 AI 技能探索与生涯规划平台**。以"技能树"为核心隐喻，用户输入专业背景与目标职业后，系统借助大语言模型（LLM）智能生成个性化的树状学习路径，并通过可视化图谱、节点对话复盘、进度追踪、职业规划等模块，打造从"认知自我"到"规划未来"的一站式学习成长工具。

产品定位：**AI 时代的个人成长导航系统**——让每一个学习者都能看清自己的技能版图，找到最优成长路径。

---

## 二、产品亮点

### 2.1 AI 智能生成技能树——千人千面的学习路径

传统学习规划依赖教科书目录或固定课程大纲，无法适配个人差异。SkillMap 基于大语言模型，根据用户输入的**专业、目标职业、当前水平**三个核心参数，动态生成专属技能树：

- **智能分层**：自动将技能节点划分为核心技能（Core）、专业技能（Specialization）和通用技能（General）三层
- **结构化输出**：每个技能节点包含名称、等级、学习步骤、推荐工具、常见陷阱和前置依赖
- **可扩展设计**：支持对已生成的技能树进行节点扩展与细化，实现"主干→分支→细节"的渐进式探索

> **区别于竞品的关键亮点**：不是简单推荐课程列表，而是生成具有拓扑关系的学习路径图，让用户直观看到"先学什么、后学什么"。

### 2.2 可视化技能图谱——一目了然的成长地图

采用专业图可视化引擎 **Cytoscape.js**，将技能树以交互式网络图形式呈现：

- **节点状态可视化**：通过颜色和标签区分"未解锁→可学习→学习中→已掌握"四种状态
- **边关系表达**：箭头连线清晰展示技能之间的前置依赖关系
- **分类色标**：按技能类别自动着色，一眼识别不同技能群组
- **交互操作**：支持缩放、拖拽、点击节点查看详情

配合 **Motion 动画库**，生成过程伴有流畅的动画过渡，提升使用体验与视觉表现力。

### 2.3 节点对话复盘——围绕技能点的深度 AI 互动

每个技能节点支持独立的**多轮对话**，用户可就具体技能与 AI 进行针对性交流：

- **精准上下文**：对话基于当前技能节点的领域知识，AI 回答更加聚焦
- **进度回写**：对话中产生的学习心得与达成情况可回写至技能节点的进度数据
- **对话保留**：所有对话历史持久化存储，支持随时回溯复习

> 这不仅是"问 AI 问题"，而是围绕技能树的**结构化学习复盘机制**，每一轮对话都在推动学习进度。

### 2.4 中国特色生涯规划体系——中西融合的理论创新

产品深度整合了**西方经典生涯理论**与**中国特色教育理念**，构建双重理论体系：

| 理论层次 | 内容 |
|---------|------|
| **西方科学方法** | Holland Code（霍兰德职业兴趣）、Career Anchors（职业锚）、Bloom's Taxonomy（认知层级）、ZPD（最近发展区）、Deliberate Practice（刻意练习） |
| **中国特色维度** | 家国情怀、义利兼顾、明德弘道、实践志向、国家战略需求匹配、社会贡献预期 |

**创新点**：在传统"个人兴趣 + 个人能力"的评估模型之上，增加了**社会维度**和**国家维度**，形成"个人—社会—国家"三位一体的生涯评估框架。这一设计既具备学术创新性，又契合当前国家对于人才全面发展的战略导向。

### 2.5 7 条差异化成长路径——不止于技能，更是人生方向

系统基于评测数据自动匹配 **7 条成长路径**：

| 路径 | 核心定位 | 国家战略契合 |
|------|---------|------------|
| 技术深耕路线 | 专业精进、技术创新 | 科技自立自强 |
| 管理发展路线 | 团队协作、战略规划 | 高素质管理人才 |
| 复合发展路线 | 跨界融合、多元能力 | 复合型人才 |
| 基层锻炼路线 | 扎根基层、服务群众 | 乡村振兴 |
| 国家战略路线 | 战略聚焦、科技攻关 | 重点领域突破 |
| 创新创业路线 | 创新思维、风险承担 | 大众创业 |
| 稳定发展路线 | 稳健可靠、服务民生 | 公共服务 |

每条路径附带详细的阶段步骤、关键技能和推荐理由，真正做到**因材施教、因势利导**。

### 2.6 时间线追踪——成长有迹可循

提供**学习时间线视图**，将用户的技能解锁、节点完成、对话复盘等事件按时间轴串联展示，形成可视化的成长轨迹。让用户清晰看到自己的进步历程，增强学习成就感和持续动力。

## 三、技术优势

### 3.1 多模型供应商架构——高可用、低成本、灵活切换

系统实现了统一的 **LLM 适配层**，支持一键切换或自动容灾切换多个 AI 模型供应商：

- **火山引擎 Ark**：主力提供商
- **硅基流动 SiliconFlow**：备用提供商
- **DeepSeek**：高性价比选择
- **Google Gemini**：多模态支持
- **通义千问 Qwen**：国产模型生态
- **自定义 OpenAI 兼容接口**：开放扩展能力

**熔断与自动切换机制**：当主提供商不可用或超时时，自动切换至备用提供商，确保服务不中断。同时内置 LLM 调用日志和 Token 用量统计，便于成本管控。

### 3.2 异步任务队列 + WebSocket 实时推送

技能树生成等 LLM 调用属于长耗时操作，系统采用**异步任务队列**架构：

```
用户请求 → 创建任务 → 后台 Worker 异步执行 → WebSocket 实时推送进度 → 前端轮询/订阅获取结果
```

- **任务状态管理**：支持 pending / processing / completed / failed 全生命周期追踪
- **重试与租约机制**：任务支持自动重试和租约过期回收，防止任务丢失
- **WebSocket 实时通信**：基于 `ws` 库实现双向消息通道，任务进度实时推送至前端
- **后台 Worker 独立进程**：`worker.ts` 与主服务进程解耦，互不阻塞

### 3.3 双数据库模式——开发便捷，生产可靠

| 模式 | 数据库 | 适用场景 |
|------|--------|---------|
| **开发模式** | SQLite（better-sqlite3） | 零配置、本地开发、单机测试 |
| **生产模式** | PostgreSQL | 高并发、分布式部署、企业级可靠性 |

- **版本化数据库迁移**：所有 Schema 变更通过迁移脚本管理（`0001_initial → 0004_tasks_retry_and_leases`），支持升级和回滚
- **自动迁移**：服务启动时自动执行未应用的迁移，零人工干预
- **环境自适应**：生产环境自动切换 PostgreSQL，开发环境默认 SQLite

### 3.4 多层安全防护体系

| 防护层 | 机制 |
|--------|------|
| **认证层** | Bearer Token + Refresh Token 双令牌机制，支持临时用户与会话管理 |
| **速率限制** | API 层 15 分钟窗口内最多 100 请求，LLM 层独立速率控制 |
| **输入安全** | 用户输入清理，防止 Prompt Injection 和 XSS 攻击 |
| **响应安全** | CSP、X-Frame-Options、X-Content-Type-Options 等安全响应头 |
| **输出过滤** | LLM 返回内容安全过滤，防止敏感信息泄露 |
| **请求追踪** | 每个请求分配唯一 Trace ID，全程可审计 |

### 3.5 现代化前端架构

- **React 19 + TypeScript**：类型安全的前端开发体验
- **Vite 构建**：极速 HMR 热更新，毫秒级开发反馈
- **Tailwind CSS v4**：原子化 CSS，样式零冲突
- **React Router v7**：声明式路由，支持懒加载
- **Custom Hooks 模式**：`useChat`、`useSkillTree`、`useWebSocket`、`useVoiceInput`、`useVoiceOutput` 等，逻辑高度复用
- **SSR 支持**：预留服务端渲染入口 `entry-server.tsx`，可扩展 SEO 优化

### 3.6 语音交互能力

内置**语音识别（STT）**和**语音合成（TTS）** Hook：
- `useVoiceInput`：将用户语音转换为文本输入
- `useVoiceOutput`：将 AI 回复转换为语音播报

提升无障碍体验，拓展多场景使用可能。

### 3.7 企业级运维能力

- **Docker 一键部署**：`docker-compose.yml` 同时拉起 PostgreSQL + Redis + 应用服务
- **PM2 进程管理**：`ecosystem.config.cjs` 支持集群模式与自动重启
- **指标监控**：`/api/metrics` 暴露系统运行指标，`MetricsService` 定期快照
- **告警服务**：`AlertService` 监控异常并触发通知
- **备份服务**：`BackupService` 支持 PostgreSQL 数据定时备份
- **CI/CD**：`.github/workflows/ci.yml` 自动化构建与测试

### 3.8 JSON 增量解析与修复——保障 LLM 输出稳定性

大语言模型的 JSON 输出天然存在不完整、格式错误的风险。系统自研了：
- **IncrementalJsonParser**：支持流式增量解析，边接收边渲染，降低用户等待感知
- **JsonRepairUtils**：自动修复 LLM 输出的 JSON 格式错误（如缺失引号、多余逗号、截断等），显著提升生成成功率
